# Speech samples

Three unmodified clips from **The Ryerson Audio-Visual Database of Emotional Speech and Song (RAVDESS)** by Steven R. Livingstone and Frank A. Russo (2018).

Source: https://zenodo.org/records/1188976
Paper: https://doi.org/10.1371/journal.pone.0196391
License: [Creative Commons Attribution-NonCommercial-ShareAlike 4.0 International](https://creativecommons.org/licenses/by-nc-sa/4.0/).
These WAV files are covered by that license, separately from the repository's code license. No audio modifications were made.

| File | Intended acted emotion |
| --- | --- |
| `03-01-01-01-01-01-01.wav` | Neutral |
| `03-01-03-01-01-01-01.wav` | Happy |
| `03-01-05-01-01-01-01.wav` | Angry |

All are actor 01 saying "Kids are talking by the door", normal intensity, first repetition. These are input examples, not evidence of classifier accuracy.
